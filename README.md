# LooKing — личный сайт (Frutiger Aero)

## Структура
- `index.html` — страница и контент (работает без JavaScript)
- `style.css` — вся графика: небо, глянец, пузыри нарисованы CSS, изображений нет
- `script.js` — необязательное улучшение: игра с мыльными пузырями
- `README.md` — этот файл

## Деплой на Vercel
1. Загрузите папку в репозиторий и на vercel.com выберите Import Project → Framework Preset: **Other** → Build/Output оставить пустыми.
2. Либо через CLI: `npm i -g vercel && vercel --prod` из папки проекта.
Никакой сборки и настроек не требуется.

## Соответствие ТЗ
- Контент, ссылки и форма полностью работают при отключённом JavaScript; кнопка пузырей без JS даже не показывается.
- Нет фреймворков, внешних скриптов, шрифтов, аналитики, fetch, localStorage, Service Worker.
- Только системные шрифты (Arial, Helvetica).
- Изображений ноль — весь визуал сделан градиентами CSS с сплошными запасными цветами для старых браузеров.
- Форма — обычные поля и стандартная отправка (mailto; замените адрес на свой).
- Вёрстка одна колонка, читается на 240x320; без flexbox/grid/переменных/анимаций.
- Градиенты продублированы в старом синтаксисе `-webkit-gradient` для браузера Android 2.x.

## Важно про Android 2.x
Сам сайт свёрстан с расчётом на браузер Android 2.x, но Vercel отдаёт страницы только по HTTPS. Старый браузер может не открыть сайт: он не поддерживает SNI и не знает современные корневые сертификаты (Let's Encrypt и т.п.), поэтому вероятна ошибка TLS-рукопожатия. Если поддержка таких устройств критична: разместите копию у хостера с доступом по HTTP или сертификатом от старого удостоверяющего центра (линейки GeoTrust/RapidSSL с корнями, которые ещё есть в хранилище Android 2.x), либо распространяйте автономную копию страницы одним файлом.
